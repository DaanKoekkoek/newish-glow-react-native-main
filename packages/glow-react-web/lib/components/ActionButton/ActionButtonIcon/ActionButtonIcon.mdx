# IconActionButton

#### Token version: {getComponentVersion("icon-action-button.v1")}

The Action Button Icon is a clickable icon centered within a circular region. It's part of the [**Action Button** ↗️](?path=/docs/designsystem-components-button-actionbutton-actionbutton--docs) component, which combines it with a text label.

## Migration Guide

When migrating from the react-native implementation, the following props should be altered accordingly:

> `onPress` is now `onClick`, but should work the same as before.
>
> `style` is removed in favour of `className`. This might require some rework on your side to abstract any custom styles into a class that can be applied.
