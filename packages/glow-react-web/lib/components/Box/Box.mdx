# Box

### Token version: {getComponentVersion("box.v1")}

The `Box` component is a fundamental building block for creating flexible and responsive layouts. It can hold one or multiple `React.ReactElement` instances and adapts to various content needs and layout structures. It also provides extensive customization options for styling through predefined properties and custom styles.

### Flex Grow

By default, the `Box` component has `flexGrow: 1`, allowing it to expand and fill the available space within its parent's height. When using it with the `Stack` component, it's better to disable this property by default, as `Stack` has options to scale the components across all breakpoints.
