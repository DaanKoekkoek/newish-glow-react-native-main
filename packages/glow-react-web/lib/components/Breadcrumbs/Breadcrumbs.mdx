# Breadcrumbs

### Token version: {getComponentVersion("breadcrumbs.v1")}

The `Breadcrumbs` component is a visual indicator of path that user is navigating through.
On mobile if there is more than 2 paths, Breadcrumb is collapsed with 3 dots - it can be expanded to show whole path of Breadcrumbs.
