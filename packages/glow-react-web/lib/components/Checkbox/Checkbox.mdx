# Checkbox

#### Token version: {getComponentVersion("checkbox.v1")}

A Checkbox is an option button that can be checked or unchecked when ticked.

To use a group of Checkboxes use the [CheckboxGroup ↗️](?path=/docs/designsystem-components-input-checkboxgroup--docs) to wrap around
your multiple checkbox options. The `helperText`, `errorMessage` & `legend` properties should only be passed into
the checkbox as props if it's used **without** the [CheckboxGroup ↗️](?path=/docs/designsystem-components-input-checkboxgroup--docs) component.

## Basic Usage

The Basic checkbox example shows a simple, non-interactive checkbox that maintains a static state.
It's ideal for displaying checkbox options in mockups or design concepts.

### Indeterminate State

The indeterminate state is useful when a checkbox represents a group of sub-options where some,
but not all, options are selected.
