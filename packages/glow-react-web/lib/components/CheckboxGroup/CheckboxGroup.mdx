# CheckboxGroup

### Token version: {getComponentVersion("checkbox-group.v1")}

A CheckboxGroup a collection of [Checkbox ↗️](?path=/docs/designsystem-components-input-checkbox--docs) components that can be checked or unchecked when ticked.
The `helperText`, `errorMessage` & `legend` properties should not be passed down into the [Checkbox ↗️](?path=/docs/designsystem-components-input-checkbox--docs) components
as props in case of using them as children.
