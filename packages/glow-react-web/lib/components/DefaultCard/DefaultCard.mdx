# DefaultCard

#### Token version: {getComponentVersion("default-card.v1")}

The `DefaultCard` component is a versatile card that can be used in various layouts with options to customize its content, appearance, and behavior.

## Purpose

The `DefaultCard` component is designed to provide a flexible, styled container for displaying various types of content. This component can include text, images, icons, badges, and pricing information. It allows customization through props like `variant`, `palette`, and `type`, making it suitable for different use cases.

## Usage

> The `DefaultCard` component can be used to display a variety of content, such as an image, title, badge, and pricing information.
>
> The `palette` prop only affects the appearance when `variant`= `outline` or `alternate`. It also affect children elements like `Badge`.

## Migration Guide

When migrating from the react-native implementation, the following props should be altered accordingly:

> **variant property value emphasized → emphasised**:
> In previous versions, the `variant` prop used the value `emphasized`.
>
> **paragraph + list properties → children**:
> The `DefaultCard` component previously used `paragraph` and `list` props to render content. These are now handled as children, providing a more flexible way to pass elements into the card.
