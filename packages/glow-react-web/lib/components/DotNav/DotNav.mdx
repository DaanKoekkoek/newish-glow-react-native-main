# DotNav

#### Token version: {getComponentVersion("dotnav.v1")}

The `DotNav` component renders a set of dots for navigation (e.g., in a slider or carousel).

## Purpose

The `DotNav` component is used as a visual navigation indicator for sliders, carousels, or any component that requires step/dot tracking. It provides both **visual feedback** (progress fill) and **interactive control** (clickable dots).

## Usage

Simply render the component with the number of dots (`count`) and optionally provide `activeIndex`, `timerDuration`, `onNext`, and `onDotClick` callbacks:
