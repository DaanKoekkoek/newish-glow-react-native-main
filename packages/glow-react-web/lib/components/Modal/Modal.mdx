# SSR Modal

### Token version: {getComponentVersion("modal.v1")}

To support server side rendering and ensure modals open correctly on initial load, you must include the following script once in your application's layout:

```sh
import SsrShowDialogScript from "@odido-portals/glow-react-web/ssr-show-dialog-script";

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html data-theme="odido-light" lang="en">
      <head>
        <SsrShowDialogScript />
      </head>
      <body>
        <Main>
          {children}
        </Main>
      </body>
    </html>
  )
};
```

This script is responsible for rehydrating and syncing modal state between the server and client.

When to Include It:

- You are using SSR and modals might be rendered on the server.

- You want to preserve the open state of the modal on hydration.

- You're relying on modal behavior being immediately interactive after SSR.

If you're only using the modal on the client side, you do not need to include this script.
