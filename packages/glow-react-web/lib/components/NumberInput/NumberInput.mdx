# NumberInput

### Token version: {getComponentVersion("number-input.v1")}

`NumberInput` is a controlled component for numeric input with optional stepper controls.
It handles increment/decrement logic, validation against min/max bounds, and supports different states and sizes.

## Usage

This component is **fully controlled** — you must pass both `value` and `onChange` to update its state.

```tsx
const [value, setValue] = useState(1);

<NumberInput value={value} onChange={(v) => setValue(v)} min={1} max={10} />;
```
