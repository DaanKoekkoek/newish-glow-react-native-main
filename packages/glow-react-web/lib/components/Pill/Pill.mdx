# Pill

### Token version: {getComponentVersion("pill.v1")}

The `Pill` component is a UI element that represents a small, rounded rectangle that can contain text Title or a Phonebrand Logo.

## Purpose

The `Pill` component creates a visual representation of a single item or a group of items.
It is often used to display tags, categories, or labels for content. Representing status indicators or filters

## Usage

**Note:** When selecting the `Logo` variant you also **need** to select a `Phonebrand` to display the logo.
