# Pincode

### Token version: {getComponentVersion("skip")}

The `Pincode` component is used for one-time verification codes. This is an extension of [guilhermerodz/input-otp](https://github.com/guilhermerodz/input-otp).

## Usage

Each `PinSlot` component represent one digit and they have to be wrapped by a `Pincode` component. The only required props on each are `maxLength` for the `Pincode` component, and a zero-based index on the `PinSlot` component. This makes creating a simple 4-digit pin component very easy, as shown below.

```ts
const maxLength = 4;

<Pincode maxLength={maxLength}>
  {[...Array(maxLength).keys()].map((_, index) => (
    <PinSlot key={`pinslot-${index}`} index={index} />
  ))}
</Pincode>
```
