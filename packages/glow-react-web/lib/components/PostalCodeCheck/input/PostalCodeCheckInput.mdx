# PostalCodeCheckInput

#### Token version: {getComponentVersion("postal-code-check-input.v1")}

A PostalCodeCheckInput is a component to gather information from user. Call out is displayed only when state on Postal Code Input is `warning` or `error` and accepts `title` and `description`.

It acccepts form as children along with `tvSectionProps` which represents Tab section for TV section - it's based on props `title`, `description` and from SegmentedTab `onTabChange` and `options`.
