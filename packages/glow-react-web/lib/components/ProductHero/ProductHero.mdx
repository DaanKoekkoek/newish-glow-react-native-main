# Product Hero

### Token version: {getComponentVersion("product-hero.v2")}

## Purpose

A Product hero is a component that can display Status and content presented within LargeSticker over image background.

LargeSticker can be used with two variants:

- variant `USP` with List items
- variant `default` with promotional description

## Default

A default version Product hero with status and LargeSticker.List
