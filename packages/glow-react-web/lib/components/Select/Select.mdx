# Select

### Token version: {getComponentVersion("select.v1")}

The `Select` component allows users to choose one option from a dropdown list. It is often used in forms or settings where the user must pick a predefined value. The component supports various configurations such as validation states, helper text, and custom options.

## Migration guide

When migrating from the react-native implementation, the following props should be altered accordingly:

- `onValueChange` → `onChange` (The event handler for value changes should now use `onChange` instead of `onValueChange` to align with the web implementation.)
- `disabled` → `inactive` (The prop to disable the select has been renamed from `disabled` to `inactive` for consistency. For backward compatibility, the `disabled` prop is still supported but deprecated.)
- `showHelper` removed. Just using `helperText` will decide whether to render the hint or not.
- `suffix` and `customSuffix` removed. Select uses a default `chevron-up` or `chevron-down` icon instead.
- `onFocus` and `onBlur` removed. Uses native :focus state instead.

## Purpose

The `Select` component creates an accessible dropdown input. It is fully customizable and provides several props for controlling the look and behavior of the dropdown, including options, value, and validation states.

## Usage

To use the `Select` component, import it and provide the required `options` along with other customizable props like `label`, `placeholder`, and `onChange`.

```tsx
import { Select } from "@odido-portals/glow-react-web/select";
import { useState } from "react";

const ControlledSelect = () => {
  const [selectedValue, setSelectedValue] = useState("");

  const handleChange = (value: string) => setSelectedValue(value);

  return (
    <Select
      id="select-example"
      legend={{
        label: "Label text",
        info: () => <Tooltip />,
        optionalText: "Extra text",
      }}
      placeholder="Choose a fruit"
      value={selectedValue}
      options={[
        { value: "tomato", name: "Tomato" },
        { value: "apple", name: "Apple" },
        { value: "banana", name: "Banana" },
      ]}
      onChange={handleChange}
    />
  );
};
```

### Grouped Options

Shows how to use the Select component with grouped options. The component automatically detects when options have a `group` property and organizes them into categories using HTML `<optgroup>` elements.

```tsx
<Select
  id="grouped-select"
  options={[
    { name: "Apple", value: "apple", group: "Fruits" },
    { name: "Banana", value: "banana", group: "Fruits" },
    { name: "Carrot", value: "carrot", group: "Vegetables" },
    // ...more options with groups
  ]}
  onChange={handleChange}
/>
```
