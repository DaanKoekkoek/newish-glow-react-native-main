# Selector

### Token version: {getComponentVersion("selector.v1")}

The `Selector` component is a versatile UI element used to represent a selectable card. It supports three variants:

- **default**: Standard layout with optional price, badge, and description.
- **compact**: Minimal layout without price, badge, or list.
- **extended**: Rich layout with optional price, badge, title strikethrough, and a list.
