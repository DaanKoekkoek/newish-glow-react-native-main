# SelectorImage

### Token version: {getComponentVersion("selector-image.v1")}

The `SelectorImage` component is a variant of the `Selector` designed for visually rich options with **images, labels, and pricing information**.  
It is typically used for product cards, plans, or offers where imagery and descriptive text help users make a choice.
