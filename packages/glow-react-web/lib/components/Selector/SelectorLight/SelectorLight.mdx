# SelectorLight

### Token version: {getComponentVersion("selectorLight.v1")}

The `SelectorLight` component is a variant of the `Selector` designed for lightweight, visually focused options.  
It is well-suited for scenarios where an icon or image represents the choice, accompanied by a short title and an optional highlight.
