# CartAccordion

### Token version: {getComponentVersion("skip")}

The `<CartAccordion>` atom is composed of multiple `<CartAccordionRow>` elements, each containing a title, a `<Price>` component, and a `<CartDetails>` component. Each row is individually collapsible, allowing users to expand or collapse content as needed.

This component is used in both the Product Detail Page (PDP) and Extras variants of the Shopping Cart.
