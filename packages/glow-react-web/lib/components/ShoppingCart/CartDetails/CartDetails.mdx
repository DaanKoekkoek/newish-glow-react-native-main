# CartDetails

### Token version: {getComponentVersion("skip")}

The `<CartDetails>` atom is used to display categorized line items within the Shopping Cart. It supports an optional `palette` prop to apply different visual themes and accepts one or more `<CartCategory>` components as children.

Each `<CartCategory>` groups related line items under a shared title.
