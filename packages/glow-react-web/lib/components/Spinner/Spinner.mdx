# Spinner

### Token version: {getComponentVersion("spinner.v1")}

When the state of a component is `loading`, you should use this component to give additional context to the user. Comes in two different sizes, along with the option to customize the text style of the indicator, for example, to match the loading icon style to that of text label style.
