# Status

### Token version: {getComponentVersion("status.v1")}

The `Status` component is a visual indicator that represents different states or outcomes through color-coded markers paired with descriptive text.

## Purpose

The `Status` component creates a consistent way to communicate the status of operations, processes, or information to users across the application.
It provides immediate visual feedback through color indicators that follow common conventions (green for success, orange for warning, red for error).

## Usage

The `Status` component requires two props:

- `type`: Defines the visual state ("success", "warning", or "error")
- `statusText`: The descriptive message that accompanies the status indicator

Use it to provide contextual feedback about actions or system states in forms, notifications, or anywhere status information needs to be displayed.
