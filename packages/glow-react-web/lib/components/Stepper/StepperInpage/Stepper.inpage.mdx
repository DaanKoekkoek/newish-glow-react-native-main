# Stepper Component

### Token version: {getComponentVersion("in-page-stepper.v1")}

This file contains the implementation of the Stepper component. Steppers typically show the user’s progress through a series of distinct steps.

Note that the number of the first step can be modified via the `startingLabel` prop on `StepperInpageProps`;
the divider after the last step is optional and can be eliminated via the `withTerminalDivider` prop on `StepperInpageProps`.

## In-Page stepper

The horizontal stepper component allows you to create a step-by-step process
with a title and state for each step.
