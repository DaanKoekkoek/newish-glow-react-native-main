# SummaryListAction

### Token version: {getComponentVersion("skip")}

The `SummaryListAction` component allows different action types, including buttons, icons, or a number input. The rendered element depends on the props passed.

## Usage

- **When `children` is provided**: Renders a `<Button />` component.
- **When only `icon` is provided**: Renders an `<ActionButtonIcon />` component.
- **When both `icon` and children is provided**: Renders a `<Button />` along with an `<Icon />`.
