# Display

Display means type intended for large sizes. When referring to optical sizing, Display is a counterpart to [`Paragraph`](?path=/docs/designsystem-typography-paragraph--docs).

## With highlights

You can apply additional styling to your display text using special formatting:

- Wrap text in square brackets (`[ ]`) to apply a highlight style. By default, this uses the palette color defined in the surrounding `<Section />` component, but you can override it using the `highlightClassName` prop.
- Use the pipe character (`|`) to insert a line break.
