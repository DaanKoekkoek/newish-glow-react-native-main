# EmphasizedHeroSection component

The `EmphasizedHeroSection` is a visually rich section layout intended for the `<EmphasizedHero />` component.

## Purpose

Use the `EmphasizedHeroSection` component to:

- Wrap the `<EmphasizedHero />` component and automatically pass down props such as `glow`, `theme`, `order`, and `palette`.
- Apply branded gradient backgrounds or provide a fully custom background.
- Align visuals and copy with flexible layout direction (`default` or `inverted`).

## Usage

Use `EmphasizedHeroSection` when you want to:

- Use the `<EmphasizedHero />` component.
- Apply gradient or custom backgrounds to enhance the visual hierarchy.
- Render a fully custom section (via `background="custom"`) when total layout control is needed.
