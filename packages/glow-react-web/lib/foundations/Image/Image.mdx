# Image Component

The `Image` component displays an image using either a locally imported asset (`localSrc`) or a remote URL (`src`). It supports two rendering modes:

> **Background mode** (default): renders the image using CSS `background-image`. <br /> **Foreground mode**: renders a standard `<img />` tag.

It also supports responsive image sets via `srcSet` (only applicable in `type="foreground"` mode).

### Wrapping Content Around Images

In **background mode**, you can wrap content around the image by passing elements as children. This is useful for overlaying text, badges, or other UI elements on top of the image.

```jsx
<Image alt="Alt text" localSrc="assets/images/mid-hero-hero.webp">
  <div style={{ padding: 16 }}>
    <Badge text="Badge text" />
  </div>
</Image>
```

## Responsive Image Example (sources)

This example shows how to use the `sources` prop with the `Image` component for responsive image rendering.

> **`sources`** defines an array of image sources, each with a corresponding `src` (image URL) and `breakpoint` (e.g., `"mobile"`, `"tablet"`, `"desktop"`).
> The browser will automatically choose the appropriate image based on the viewport size.

### Example usage

- A `type="foreground"` renders the image as an `<img />` tag.
- The `sources` prop is used to provide different image sources for different breakpoints, ensuring the correct image is selected for various screen sizes.
