# Logos

The `Logos` component is used to render brand-specific SVG logos.
The `Logos` component renders a brand logo as an SVG element. It supports different size and color variations, making it adaptable to various design needs.
The `Logos` component provides a flexible way to display brand logos, supporting multiple brands and variants. It automatically determines the logo based on the configured brand in `<ThemeProvider />`, but it can also be overridden using the `brand` prop.

## Migration guide

When migrating from the react-native implementation, the following props should be altered accordingly:
