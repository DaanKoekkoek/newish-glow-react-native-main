# Payments Logos

The `Pay` component is used to display various payment method logos in a consistent and visually appealing manner.

## Purpose

The `Pay` component creates a standardized way to present payment method logos across the application, ensuring that they are displayed correctly and uniformly.

## Usage

The `Pay` component can be used in any part of the application where payment method logos need to be displayed.
It could supports multiple payment methods. Currently we have `iDEAL` & `iDIN`.
