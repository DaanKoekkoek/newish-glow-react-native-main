# PhoneBrand

The `PhoneBrand` component displays SVG logos for various phone brands.

## Usage

- `variant`: Use the **inverted** option when the logo is placed on a dark background to ensure visibility.
- `ariaLabel`: Use this prop to provide multi-language support.
  The string should include `{brand}` which will be replaced with the actual brand name.
