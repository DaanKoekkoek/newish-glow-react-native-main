# CheckboxGroup

A CheckboxGroup a collection of [`Checkbox`](?path=/docs/checkbox--docs) components that can be checked or unchecked when ticked.
The `helperText`, `errorMessage` & `legend` properties should not be passed down into the [`Checkbox`](?path=/docs/checkbox--docs) components
as props in case of using them as children.
