# LargeSticker

## Purpose

The `LargeSticker` component is large version of default `Sticker` component, it can accept `Price` or `DefaultList` as components.

`Default` variant accepts description with `description` property.

## Price component

`Price` component props that are overriden from basic component are:

- `size=lg`
- `inverted` controlled by palette of `LargeSticker`
