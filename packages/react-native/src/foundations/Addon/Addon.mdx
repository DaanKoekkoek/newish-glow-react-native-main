# Addon

An addon is an image containing an addon offering. You have the option to adjust the size of the addon container, but will automatically adjust its size based on the breakpoint.

## With Grid

While `size` values of `"sm"` and `"xs"` have a fixed width and height, `default` does not. Default scales based on the parent container. In the example below, `Grid` in combination with `Stack`, `Heading` and `Paragraph` is used.
