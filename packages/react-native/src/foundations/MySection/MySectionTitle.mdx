# MySection.Title

## Purpose

`MySection.Title` is a subcomponent of `MySection` designed to add a heading element. It helps provide a clear structure and contextual meaning to the accompanying `MySection.Content` blocks.

## Features

- **Customizable Heading Size**: Adjust the heading size using the `size` prop, which accepts standard options like `md`, `lg`, and `xl`.
- **Semantic HTML Support**: Renders as an `<h2>` element by default, ensuring proper accessibility and SEO compliance.

## Usage

Within `<MySection>`, include a `<MySection.Title />` block. Use the `size` property to control the heading's visual hierarchy.
